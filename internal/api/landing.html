Device Registry API

A REST service to register and track devices such as cameras and sensors, with secure login, role based access and safe concurrent updates.

GoPostgreSQLMongoDBJWTDocker
View sourceAPI reference

JWT authentication

Token login with admin and viewer roles. Viewers can read, admins can change data.

Safe updates

Every device has a version. A stale ETag in If-Match gets 412, so no one overwrites another change.

Swappable storage

The same code runs on memory, PostgreSQL or MongoDB, checked by one shared test suite.

API reference

Everything except login and health needs an Authorization: Bearer token.

POST/auth/tokenLog in and receive a token
GET/devicesList devices
GET/devices/{id}Get one device
POST/devicesCreate a deviceadmin
PUT/devices/{id}Update with If-Matchadmin
DELETE/devices/{id}Delete a deviceadmin
GET/healthzHealth check

Quick start

Replace the placeholders with your own login.

# 1. log in
curl -X POST https://device-registry.onrender.com/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"username":"USER","password":"PASSWORD"}'

# 2. create a device
curl -X POST https://device-registry.onrender.com/devices \
  -H 'Authorization: Bearer TOKEN' -H 'Content-Type: application/json' \
  -d '{"name":"lobby-cam","kind":"camera","address":"192.168.1.20","status":"online"}'

Login details are private. A Postman collection and full documentation are in the repository. This runs on a free host, so the first request after a long quiet period can take a little while.
